# Cohorte de Trabajadores de la Salud

Sitio estático en HTML, CSS y JavaScript. Los archivos del sitio están en la raíz de este paquete, por lo que se pueden copiar directamente a la raíz del repositorio.

## Publicar con GitHub Pages

1. Sube el contenido de este ZIP a la rama principal del repositorio.
2. En GitHub, abre **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**, la rama principal y la carpeta **/(root)**.
4. Guarda los cambios y consulta la URL que GitHub Pages muestra en esa sección.

La página principal es `index.html`. Incluye los recursos, páginas de instituciones, equipo, aviso de privacidad, publicaciones, solicitud de acceso a datos y propuesta de inicio de sesión.
